How this works

web/selftest/make_fixtures.py uses the repo's Python (gottlux.synthetic + gottlux.io.writer + gottlux.io.decode) to write an EVT2.1 fixture with a planted 200 Hz flutter target and a hand-packed EVT2.0 fixture, then records what the Python decoder produces (counts, spans, checksums) as expected.json. This page decodes the same bytes with the JS decoder and compares every field, then runs the JS region spectrum on the planted target and asserts the peak is within 2 Hz of the planted frequency.
